# Portfolio – webdevSandy

Welcome to my personal portfolio website repository! This project is designed to showcase my projects, technical skills, and journey as a web developer. Built using React and Vite, the site features a modern, responsive layout and smooth user experience.

## 🌐 Live Demo

Visit the live site:  
https://webdevsandy.vercel.app/

*******************************************

## 🚀 Tech Stack

- **Frontend:** React, Vite
- **Styling:** CSS3, HTML5, Tailwind CSS
- **Build Tools:** Vite, ESLint
- **Deployment:** Vercel

## ✨ Features

- Responsive modern design for all devices
- Smooth animations and UI transitions
- Projects portfolio with live demo links
- Detailed About and Skills sections
- Integrated contact form for quick messaging

## 🛠️ Getting Started

To run a local copy:

Clone the repository

git clone https://github.com/webdevSandy/Portfolio.git
Enter the directory

cd Portfolio
Install dependencies

npm install
Start the development server

npm run dev

text

Open [http://localhost:5173](http://localhost:5173) in your browser to see the site.
